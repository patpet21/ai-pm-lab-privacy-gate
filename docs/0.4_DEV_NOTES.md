# AI PM LAB Privacy Gate 0.4 development notes

Status: internal development build. Do not publish as the public Windows release until final regression testing and SignPath integration are complete.

## Implemented in 0.4.0.dev1

- schema migration from library v1 to v2 with an automatic pre-migration database copy;
- encrypted `.pgbackup` export and validated restore, protected with Windows DPAPI for the current user;
- recoverable trash, permanent deletion confirmation, favorites, rename and editable labels;
- library TXT and JSON export;
- second Presidio scan of the exact protected copy before clipboard, download, or opening an AI service;
- reversible, generic, masked and permanent-redaction modes;
- configurable detection confidence;
- secure layout-preserving PDF export: source pages are rasterized locally and selected PII is replaced at its original coordinates with color-coded labels;
- side-by-side original/protected PDF preview with synchronized page navigation and zoom controls;
- contextual information buttons, resettable selection filters, clearer detected/protected counts and an icon-based collapsed sidebar;
- universal protection scopes for Essential PII, Financial, Business Confidential, Maximum and Custom Review;
- context-aware financial and general-business recognizers which override generic numeric guesses for accounts, routing/SWIFT, card endings, transaction IDs, amounts, merchants, counterparties, references, addresses, registrations, invoices, purchase orders, contracts, customers, employees and cases;
- additional U.S. real-estate recognizers for EIN, property/APN, unit, access and lockbox codes, contractor license, insurance claim, utility account, loan and transaction identifiers;
- visible internal-build version marking so development installers cannot be mistaken for public releases.

## Still planned before public 0.4

- safe update manifest and rollback workflow;
- batch document queue with mandatory per-document review;
- optional local OCR feasibility test for scanned PDFs;
- optional PDF protection/export report;
- onboarding and sample workspace;
- broader regression corpus for real-estate false positives and missed values;
- SignPath two-stage EXE and installer signing after Foundation approval.

MCP, n8n execution, LLM integrations and cloud automation remain disabled. The application boundary and local API package stay available for later implementation.
