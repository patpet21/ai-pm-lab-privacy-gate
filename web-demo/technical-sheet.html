TECHNICAL PRODUCT SHEET

AI PM LAB Privacy Gate

Version 0.4.0 · local-first PII protection for real-estate operations

LOCAL CORE

Product purpose

Windows desktop application that detects and replaces personally identifiable information before operational documents are used with AI. The core protection and restoration workflow requires no Privacy Gate account, subscription, API key, or cloud service.

Technical specifications

Detection engineMicrosoft Presidio with spaCy NLP context and custom U.S./real-estate recognizers
Supported inputPasted text and text-based PDF
OutputProtected TXT/PDF, redaction, or reversible placeholders
ProfilesProperty Management; Realtor/Brokerage; Projects & Renovations
StorageEncrypted local library under the operating-system user
DatabaseNo mandatory central document database
ConnectivityOptional authenticated MCP for protected library copies only
Operating systemWindows 10/11 64-bit; macOS build planned
OCRNot included in 0.4.0; scanned/image-only PDFs are rejected
Cloud / LLMNo LLM integration or API key required for the core app

Security and privacy boundary

  • Original documents are processed locally and are not published through MCP.
  • Reversible mappings and restore keys remain local and structurally outside the Protected Library exposed to AI.
  • Users review and can deselect findings before generating a protected copy.
  • Remote connectivity is optional, TLS-protected, authenticated, outbound-only, and available only while the device is online.

Regulatory support

Designed to support GDPR privacy-by-design and data-minimization practices, EU AI Act human-oversight and data-governance workflows, and U.S. privacy/security controls including CCPA/CPRA and the NY SHIELD Act.

Important: Privacy Gate is a technical safeguard, not legal advice, an audit, or a certification of compliance. Organizational compliance depends on the complete workflow, policies, contracts, jurisdiction, and use case.

Distribution and support

Free application and public source repository. Optional paid consulting is available for n8n, MCP, AI, email, document, and real-estate workflow implementation.
