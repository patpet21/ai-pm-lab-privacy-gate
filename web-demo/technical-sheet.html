TECHNICAL PRODUCT SHEET

AI PM LAB Privacy Gate

Version 0.5.0 · local-first sensitive-data protection for real-estate and business operations

LOCAL CORE

Product purpose

Windows and macOS desktop application that detects and protects sensitive information before operational documents, printed document images, or screenshots are used with AI. The core protection and restoration workflow requires no AI API key or mandatory cloud document-processing service.

Technical specifications

Detection engineMicrosoft Presidio with spaCy NLP context, custom real-estate recognizers, English and Italian detection guardrails, plus local OCR for printed images
Supported inputPasted text; TXT; text-based PDF; Word DOCX; Excel XLSX; PowerPoint PPTX; PNG; JPG/JPEG
Image OCRLocal OCR for printed PNG/JPG/JPEG document images and screenshots, with geometry-aware pixel-level redaction. Handwriting is not supported.
OutputProtected source-format copies, reversible placeholders where supported, pixel-redacted images, and OCR text companions for protected images
ProfilesProperty Management; Realtor/Brokerage; Projects & Renovations
StorageEncrypted local library under the operating-system user; DPAPI on Windows and Keychain-backed encryption on macOS
DatabaseNo mandatory central document database for the local protection workflow
ConnectivityOptional authenticated MCP for already-protected Library copies; supported Google Drive and Gmail source workflows
Operating systemWindows 10/11 64-bit; macOS 12+ on Apple Silicon or Intel
Scanned PDFsOCR for scanned/image-only PDF pages is not included in 0.5.0; image OCR currently targets PNG/JPG/JPEG inputs
Cloud / LLMNo LLM integration or API key required for the core local protection workflow
UpdatesMicrosoft Store-managed updates for the Store edition; verified direct-update workflow for supported Windows and macOS direct releases

Security and privacy boundary

  • Original documents and image pixels are processed locally by the protection pipeline.
  • Reversible mappings and restore keys remain local and structurally outside the Protected Library exposed to AI through MCP.
  • Users review findings and can keep or protect individual detected values before generating a safe copy.
  • Protected images use destructive pixel redaction rather than a cosmetic overlay-only approach.
  • Optional remote connectivity is authenticated and exposes only already-protected Library content, never original values or restore mappings.

Regulatory support

Designed to support GDPR privacy-by-design and data-minimization practices, EU AI Act human-oversight and data-governance workflows, and U.S. privacy/security controls including CCPA/CPRA and the NY SHIELD Act.

Important: Privacy Gate is a technical safeguard, not legal advice, an audit, or a certification of compliance. Automated detection may require human review, and organizational compliance depends on the complete workflow, policies, contracts, jurisdiction, and use case.

Distribution and support

Privacy Gate 0.5.0 is available for Windows and macOS. The Microsoft Store edition is signed and distributed through Microsoft Store. Direct Windows and macOS release artifacts are published with SHA-256 checksums; current direct macOS packages are not Apple-notarized.
