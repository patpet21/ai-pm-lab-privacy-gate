# PrivacyGate Browser Protection 0.0.66 — Store Release Test Matrix

Release branch: `fix/browser-extension-store-hardening-20260909`

Release baseline: `8dce4abcedbdb176d9df975d9e26cd074534a50d`

Target browsers: Google Chrome and Microsoft Edge

Supported AI providers: ChatGPT, Claude, Gemini

## Release invariant

While PrivacyGate protection is ON, every failure must fail closed:

- an original file must never be substituted as a fallback when local file protection fails;
- clear restored PII must never be written into the AI provider's page DOM by the secure restore path;
- a failed or unverified protected text send must not fall back to the original unprotected prompt.
